# Sultan Mahamud Opu — Academic Portfolio

A modern academic/research portfolio built with plain HTML, CSS and JavaScript.

## Folder structure

```text
opu-portfolio/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── cv.pdf
    └── my.JPG
```

## Setup

1. Put your final CV PDF at `assets/cv.pdf`.
2. Put your photo at `assets/my.JPG`.
3. Open `index.html` locally, or deploy the folder to GitHub Pages.

## GitHub Pages

Create a repository (for example `SultanMahamudOpu.github.io`), upload the files, then enable GitHub Pages from the repository settings.

## Important

Project links and publication details are based on the supplied CV. Empty GitHub/live-demo fields are intentionally not shown until a real link is available.
